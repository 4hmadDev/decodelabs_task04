# Sales Data Visualization Using Python

### Decode Labs Internship — Project 4

## Project Overview

This project focuses on analyzing and visualizing sales data using Python. The main objective is to create meaningful visualizations that help identify sales patterns, product performance, payment preferences, and relationships between numerical variables.

## Tools & Libraries

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The dataset contains sales transaction records with information such as:

- Order ID and Date
- Product and Quantity
- Unit Price and Total Price
- Payment Method
- Order Status
- Customer ID

## Visualizations

### 1. Bar Chart — Product Sales
Compared the total quantities sold across different products to identify the best-selling products.

### 2. Pie Chart — Payment Method Distribution
Visualized the percentage of orders associated with different payment methods.

### 3. Line Chart — Monthly Sales Trend
Analyzed monthly order values to understand sales fluctuations over time.

### 4. Histogram — Order Value Distribution
Examined the frequency distribution of order values and identified patterns in transaction amounts.

### 5. Correlation Heatmap
Used Seaborn to examine correlations between Quantity, UnitPrice, ItemsInCart, and TotalPrice.

## Key Insights

- Chairs recorded the highest quantity sold among the products.
- Online payments represented 21.5% of all orders.
- June 2024 had the highest monthly recorded order value.
- The distribution of order values was positively skewed.
- UnitPrice and TotalPrice showed a positive correlation of 0.72.
